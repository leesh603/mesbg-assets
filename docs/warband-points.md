# 워밴드 포인트 편성 — 2026-10-14

워밴드 인원 정원을 포인트 예산으로 교체했다. 영입에는 금화가 들며,
살아 있는 영구 동료의 프로필 포인트 합계가 편성 한도를 점유한다.

- 새 원정은 **300pt**. 구매마다 **+50pt**. 비용은 첫 구매 45금화,
  이후 구매당 25금화 증가. 스테이지 진입만으로 한도가 늘어나지 않는다.
- 일반 병사는 후보별 `+/−`로 여러 기를 선택한다. 영웅과 유니크 인물은
  한 기만 가능하며, 시작 영웅 최대 한 기 규칙도 유지한다.
- 선택과 확정 양쪽에서 금화·포인트·유니크 중복을 다시 검증한다.
  배치 실패 시 배치한 전체 묶음, 금화, 후보 구매 상태, UID를 복구한다.
- 기마·특수 탈것 전환은 새 프로필과 기존 프로필의 포인트 차이를 검사한다.
  실패하면 금화와 군마를 소비하지 않는다. 낙마하면 도보 포인트를 쓴다.
- 임시 지원병은 제외. 전사자는 제외. 부상·경험치·남은 자원 때문에 비용을
  할인하지 않는다. 원정 유물·전리품 장비의 능력은 추가 편성 비용이 없다.
- 구출·진화·부활로 얻은 동료와 형태도 합산한다. 이 보상으로 한도가 넘으면
  기존 동료와 전투 진행은 유지하고, 추가 영입·탈것 구입은 한도 확장 전까지
  제한한다. 영입 건너뛰기는 허용한다.
- 기존 세이브는 살아 있는 동료를 모두 유지한다. 이미 구매한 증원은 구매당
  50pt로 변환하고, 필요하면 현재 편성 합계를 50pt 단위로 올린 한도를 적용한다.
  변환 뒤 한도는 고정되며, 사망·재접속으로 증가하지 않는다.

## 비용 자료와 한계

`src/warband-points.js`의 492개 프로필 중 354개는 현재 대조 자료의 정확한
프로필·허용 무장 조합을 쓴다. 나머지 138개는 게임 전용 인물·무장·탈것,
혹은 동일 공식 프로필이 확인되지 않아 따로 산정한 형태다.

판본은 MESBG 2024 계열 규칙과 2024–2025 아미 프로필이다.
공개 GW **Legacies of Middle-earth, Forces of Good / Evil** PDF의 비용·무장과
대조했다. 유료 아미북 부분은 아래 공개 아미빌더의 전사 자료를 이용했다.
**모든 유료 아미북 원문을 직접 열람·검증했다는 뜻은 아니다.**
다른 판본, 군대 전용 무료 옵션, 다른 인물을 이름만으로 혼용하지 않는다.
공식값 여부는 모집 카드·상세 프로필에서 구분한다.

자료:

- [GW Good Legacy PDF](https://assets.warhammer-community.com/eng_jun25_mesbg_legacies_of_me_good-qo0xxvhunb-sz3xumksvr.pdf)
- [GW Evil Legacy PDF](https://assets.warhammer-community.com/eng_jun25_mesbg_legacies_of_me_evil-niah1kdjlp-rjgdfvdryx.pdf)
- [아미북 전사 데이터 — 고정 커밋](https://github.com/mhollink/mesbg-list-builder-v2024/blob/06f1056742d8bc960d45b7427c62c6d9a1c97125/src/assets/data/mesbg_data.json)
  Git blob: `d1cf99b028fcc80c03eb47762b1a005a01613eff`.

예: 미나스 티리스 전사 8 + 방패 1 = 9pt; 창·방패 10pt;
로한 기수 14 + 투창 2 = 16pt; 아라곤 스트라이더 160 + 갑옷 5 = 165pt.
이 게임의 보로미르는 백색탑 대장 프로필과 방패로 165pt를 쓴다.
핑골핀은 길갈라드를 비교 기준으로 210pt, 기마는 230pt다.

자체 산정은 유사한 공식 프로필의 포인트에 게임 스탯 차이를 더한다.
F 5, S 7, D 3, A 20, W 25, C 2, Might 6, Will 3, Fate 5pt의
차이 가중치, 6인치 초과 이동 1인치당 2pt, 기마 20, 비행 30,
공포 10, 두려움 없음 5, 창 지원 1, 사격과 명중률을 고려했다.
일반 병사는 1pt 단위, 영웅·괴수 등은 5pt 단위로 반올림한다.
각 결과의 비교 유닛, 기준 비용과 차이는 `warband-points-audit.json`에 있다.

## 검증

관련 자동 테스트 40개 통과: 비용 전수, 300pt 경계, 8명 초과 일반 병사 편성,
복수 영웅 제한, 증원 구매, 수량·금화·포인트 재검증, 배치 실패 원자성,
기마/특수 탈것, 임시 지원병, 사망·부상, 구세이브 변환, 진화 후 초과와
영입 건너뛰기, 200개 시드의 초기 후보 생성, 기존 무료 영웅 능력과 저장 복원.

실제 브라우저에서 모바일 360·390px 및 PC 1280px의 영입→10명 배치→출전을
검증했다. 가로 넘침 없음, 수량 버튼 최소 44×44px, 모든 후보에 pt 표시,
프로필 열기·닫기 정상, JavaScript 오류 없음. 전투 진행 중 사망에 따라
편성 사용 포인트가 감소하는 것도 확인했다.

추가 실행한 기존 `progression.test.cjs`는 14개 통과·2개 실패다.
변경 전 main 소스로도 동일하게 실패했다: 사운드 mock의 `wt.play` 누락,
클라우드 복원 renderer mock의 호출 횟수 기대값. 이 변경과 무관한 기존
테스트 fixture 문제이며 실제 브라우저에서는 해당 오류가 발생하지 않았다.

빌드: `node tools/build.js --online-only`.
테스트: `node --test tests/warband-points.test.cjs tests/free-hero-activation.test.cjs tests/qa-state.test.cjs`.
브라우저: `node tests/warband-points-browser.cjs` (전체 리포 에셋, Playwright Chromium).
