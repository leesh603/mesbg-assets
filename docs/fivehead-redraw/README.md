# 5등신 쿼터뷰 통일 — 다시 그릴 유닛 목록

목표: 모든 인간형 유닛을 5등신 쿼터뷰 그림으로 통일한 뒤, 받침도 전부 같은 방식(납작한 원판 위에 발을 세움)으로 바꾼다.

## 현재 상태 (2026-10-19 기준)

| 구분 | 수 |
|---|---|
| 이미 5등신 쿼터뷰로 다시 그림 (`art-src/fivehead-20261019`, `roster-unify-20261019`, `unit-redraw-20261019`, `osgiliath-legs-20261019`) | 73 |
| 다시 그려야 함 — 도보 | 325 |
| 다시 그려야 함 — 기마 | 76 |
| 대상 아님 (용·늑대·독수리·거미·박쥐·무리 등 네발/비행 짐승) | 36 |

- 판정은 "최근 다시 그린 배치에 들어 있는가"를 기준으로 했다. 목록 시트를 눈으로 훑어보니, 남은 유닛 중 일부(예: `arvedui`, `dol_amroth_man_at_arms`, `gondolin_guard`, `noldor_warrior`)는 이미 꽤 비슷해서 다시 그리지 않고 통과시켜도 될 수 있다. 엔트(`beechbone`, `leaflock` 등)는 인간형이지만 비율 기준을 따로 정해야 한다.
- 전체 목록과 상태: `inventory.json` (`status`: done / todo / n/a-beast, `priority`, `kind`: foot / mounted).

## 우선순위

1. **P1 (158명)** — 시작 편성과 2공세 이전에 영입할 수 있는 유닛. 플레이어가 가장 자주 본다. `todo-p1-01~04.png`
2. **P2 (219명)** — 맵 테마에서 적으로 나오는 유닛과 나머지 영입 유닛. `todo-p2-01~05.png`
3. **P3 (24명)** — 이벤트·후반 전용 등 드물게 나오는 유닛. `todo-p3-01.png`

## 그림 기준 (`style-reference.png`)

- 머리 크기가 전체 키의 약 1/5. 정수리부터 발바닥까지 다 보이게.
- 정면 쪽으로 살짝 돌린 쿼터뷰. 얼굴과 가슴이 보이고, 위에서 내려다보는 각도는 지금 예전 그림보다 얕게.
- 두 발이 땅을 디딘 자세. 발밑에 그림자나 받침은 그리지 않는다 (게임이 받침을 따로 깐다).
- 기존 그림의 장비·색·문장은 그대로 유지한다. 바꾸는 것은 비율과 시점만.
- 기마: 말도 같은 쿼터뷰로. 말발굽 네 개가 보이도록.
- 투명 배경 PNG, 기존과 비슷한 해상도(긴 변 320~380px).

## 새 그림이 들어오면

1. `art-src/<배치 이름>/`에 원본을 넣고, `tokens/<id>.png`와 `assets/mesbg/tokens/<id>.png`를 교체한다.
2. `docs/unit-art-audit.json`에서 해당 유닛의 키 기준점(정수리/발바닥)을 검수하고 `node tools/calibrate-unit-stature.cjs --write`를 실행한다.
3. `inventory.json`에서 `status`를 `done`으로 바꾼다.

## 받침 전환 계획

- 발을 받침 중앙에 세우고 받침을 납작하게 눕히는 코드는 `exp/flat-base-feet-anchor` 브랜치에 있다(5등신 유닛만 적용하는 시험판).
- 같은 전장에 둥근 받침과 납작한 받침이 섞이면 어색하므로, **인간형 유닛이 거의 다 다시 그려질 때까지 main은 지금의 둥근 받침을 유지**한다.
- 전환할 때는 모든 유닛에 같은 납작한 받침을 쓰고, 선택 링·이동 범위·교전 범위 표시도 같은 비율로 맞춘다. 규칙 판정(접촉·거리)은 원형 그대로 둔다.
