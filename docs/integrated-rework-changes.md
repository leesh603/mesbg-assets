## UI·전술·원정

- 이어하기 요약, 저장 덮어쓰기 확인, 부대·도감 검색.
- 두 열 편성 카드, 실제 역할, 고정 비용·선택 요약과 확정 조작.
- 다음 전장 우선 배치, 부대 상세 접기, 출발 버튼 유지.
- 자동 진행 중 집중 대상 / 전열 유지 / 지휘 해제. 위치·행동·자원 추가 없음.
- 정찰 성공 → 다음 전장 공개와 첫 라운드 우선권.
- 호위 성공·치료 사건 → 다음 전투의 임시 지원병.
- 실제 회복·창 지원 집계. 명예록은 ‘전사한 전우’로 표기.

## 실제 브라우저 기록

GitHub Actions의 격리 Chromium에서 정상 UI로 진행한다. POST 및 랭킹 서버 접속 차단. 수치 조작·강제 승리 없음.

초기 검증 `c276617`은 새 코드 실행으로 교체하기 전 4공세 11라운드까지 정상 진행했다. 이 실행은 **취소**되었으며 클리어/패배 기록으로 세지 않는다. 360×740·390×844의 메인/편성/배치 화면과 390×844 야영 화면을 확보했다. 당시 콘솔 오류 0, 캡처 시 가로 넘침 0. 두 이미지 요청 취소는 기록에 남아 있다.

캡처 검수에서 새 CSS가 기존의 높은 우선순위 규칙에 덮이는 문제를 발견해 수정했다. 최종 화면은 후속 Actions 산출물에서 재확인해야 한다. 첫 보스·전체 원정 결과 및 최종 성능 수치는 확정 전이다.
