현재 결과
실제 제작된 신규 곡: 0곡. 신규 청취 파일: 없음.
Runway 연결은 완료했으나 Free 플랜의 음악 생성 제한으로 제작 및 게임 적용은 미완료다.
기존 MP3, 합성 음악, 효과음을 신규 오리지널 OST로 간주하지 않았다.
게임 소스, 그래픽, 기존 음원, index.html은 수정하지 않았다.
main 병합, 원격 푸시, 배포는 하지 않았다.

제작 수단 확인
사용자는 Runway 연결 후 기능 확인을 선택했다.
초기 검색에서는 미설치였고 브라우저는 guest 및 Models unavailable을 표시했다.
이후 사용자가 Runway를 설치·연결했으며 커넥터 인증 성공을 확인했다.
메인 테마 생성 요청을 실제 제출했으나 paid_plan_required로 차단되어
작업 ID와 음원은 생성되지 않았다. 같은 요청을 반복하지 않았다.
현재 계정은 Free 플랜이다. 크레딧 잔액과 별개로 음악 생성은 유료 플랜이 필요하다.
결제, 구독 변경 또는 체험 시작은 수행하지 않았다.
확인된 완성곡 모델은 Lyria 3 Pro이며 출력은 MP3, 회당 8크레딧이다.
일곱 곡의 최초 후보 생성은 56크레딧이고 재제작 비용은 별도다.
길이는 모델별 고정이며 API에 duration 매개변수가 없다.
따라서 명세의 목표 길이를 직접 지정할 수 있다고 보장하지 않는다.
스템, 합창의 세부 제어, 구간 편집 및 루프 품질은 미검증이다.
공식 Agent 문서에는 standalone instrumental music 생성이 명시되어 있다.
https://help.runwayml.com/hc/en-us/articles/51601639579667-Creating-with-Runway-Agent
공식 사용 권한 안내는 상업적 이용을 허용하며 의무 크레딧을 요구하지 않는다.
https://help.runwayml.com/hc/en-us/articles/18927776141715-Usage-rights
실제 계정의 플랜·크레딧 및 도구의 모델·출력 제약은 확인했다.
실제 곡 길이, 무손실 출력, 무가사 합창, 스템/구간 편집은 검증하지 못했다.
서비스의 일반적인 상업적 사용 안내만으로 실제 곡의 권리 검증을 완료했다고
간주하지 않는다. 선택 모델의 조건과 제작 이력을 함께 기록해야 한다.

기존 재생 구조 (src/game.js, 분석 기준 커밋의 줄 번호)
421–445: We 클래스. BGM은 단일 HTMLAudioElement, 효과음은 Web Audio.
424: setMood가 music.src를 즉시 교체한다. 페이드 처리가 없다.
425: 승패 fanfare는 sawtooth oscillator로 합성한다.
426–427: unlock은 lwb-camp.mp3를 생성하고 AudioContext.resume을 호출한다.
428–432: lwb-audio의 muted/sfxVolume/musicVolume 저장과 음량 제어.
433–445: 효과음은 fetch/decode 후 buffers Map에 캐시한다.
494: Ut가 외부 assets/mesbg 경로 또는 오프라인 내장 에셋을 반환한다.
500: 화면 숨김 시 BGM과 AudioContext를 중단하고 복귀 시 재개한다.
508–585: MP3 위에 합성 드론·선율·북·호른을 중첩하는 음악층이 있다.
516 및 424: 막별 playbackRate와 보스 1.05배 변경이 있다.
527–534: Rohan/Mordor/Elf/Moria/Isengard/Mirkwood 맵별 트랙 매핑.
Gondor 전용 매핑은 없으며 해당 맵은 일반 전투곡으로 폴백한다.
535: setMap은 mood=-1로 바꾸어 다음 setMood 호출의 재선택을 유도한다.
5340–5342: renderDock는 mood → act → map 순으로 호출한다.
따라서 맵 변경이 해당 호출에서 즉시 곡 선택에 반영되지 않는 구조다.
menu/reward/result는 모두 mood 0으로 묶여 캠프 음악을 공유한다.
보스 판단은 q.current.boss에 의존한다. 영웅이 있다는 이유만으로 보스곡을
재생하면 정상 전투 대부분이 보스곡으로 바뀔 수 있으므로 별도 대결 조건이 필요하다.
2414 및 3283: 스테이지 완료/런 종료의 fanfare 훅.
764–773: 기존 음향 창, 슬라이더, 음소거 버튼. 유지 대상이다.

신규 곡과 적용 설계 (아직 구현하지 않음)
곡별 편성·전개·목표 길이는 ost-production-status.json에 기록했다.
메인 > 결과 > 준비/지역 > 실제 전투 단계 구분을 명확히 한다.
보스곡은 보스의 실제 전투 상태에서 일반 전투곡보다 우선한다.
Rohan: helms_deep, edoras, dunharrow.
Gondor: minas_tirith, osgiliath, pelennor.
Mordor: black_gate, gorgoroth, dol_guldur, angband.
그 밖의 지역/캠프의 처리 방침은 기존 전용곡 유지 또는 승인된 신규곡과의
연결을 결정해야 한다. 일곱 곡만으로 모든 지역의 정체성을 충족한다고 하지 않는다.
실제 파일·길이·루프 지점과 권리가 검증된 뒤 트랙 레지스트리를 활성화한다.
고품질 OST 적용 시 기존 합성 BGM층과 음악용 playbackRate 변경을 제거한다.
효과음 재생, 효과음 음량, 저장 설정과 기존 전쟁 나팔은 보존한다.
Aftermath는 승패 상태를 받아 한 번 재생하고 반복적인 결말 재시작을 피한다.
음악에는 Web Audio GainNode를 통한 약 1.5초 페이드를 검토한다.
iOS에서 HTMLMediaElement.volume 제어만으로 페이드를 보장하지 않는다.
현재/다음 트랙 최대 두 개의 미디어 요소를 재사용하고 요청 세대 번호를 둬서
빠른 장면 전환의 오래된 로드 완료/재생 요청을 무효화한다.
사용자 입력에서 두 미디어 요소와 AudioContext를 해제하고 play 실패를
분류한다. 숨김·음소거·음량 0일 때 로드 완료로 재생이 다시 시작되지 않게 한다.

용량 및 성능 (실측과 예상 구분)
현재 저장소 MP3 10개 합계: 8,338,395 bytes. 전체 에셋 용량을 뜻하지 않는다.
신규 목표 길이 합계: 756초. 이는 실제 제작 길이가 아니다.
160kbps MP3 예산: 약 15.12MB, 96kbps Opus 예산: 약 9.07MB.
두 형식을 모두 저장하면 약 24.19MB + 메타데이터이며 브라우저에는
지원되는 한 형식만 요청한다. WAV 마스터는 모바일 초기 다운로드에서 제외한다.
120초 곡을 44.1kHz 스테레오 float32로 모두 디코딩하면 약 42.3MB이므로
일곱 곡 전체 AudioBuffer 사전 디코딩은 피하고 미디어 스트리밍을 검토한다.
루프 경계는 컨테이너/인코더 지연까지 고려해 실제 청취로 확인한다.
MP3를 기본 호환 후보, Opus를 선택 최적화 후보로 두되 실제 기기에서
canPlayType, 재생, 반복 및 오류 폴백을 검증한 뒤 형식을 확정한다.
가용 음원이 없으므로 LUFS, true peak, 실제 길이와 메모리 실측은 미실시다.

권리 기록
음악 생성 요청은 계정 제한으로 제작 실행 전에 차단됐다. 사용된 신규 음원·샘플은 없다.
기존 MP3의 제작 출처/사용 권리는 이번 분석으로 검증되지 않았다.
생성할 각 곡의 모델, 생성일, 계정/플랜, 작업 ID, 원본 파일 해시,
게임 삽입·편집·루프·압축·공개 웹 에셋 제공 허용 근거를 기록해야 한다.
실제 청취를 통해 기존 영화 음악의 인지 가능한 선율 복제를 배제한다.
독립 작곡가 제작을 선택하면 같은 항목을 계약 및 샘플 라이선스로 확인한다.

실제 검증 상태
완료: 저장소 원본 및 빌드 흐름 읽기, 오디오 훅 분석, MP3 파일 크기 조사,
공식 서비스 문서 확인, 초기 브라우저의 게스트 상태 확인,
이후 Runway 커넥터 인증·플랜 확인 및 실제 음악 생성 요청의 유료 플랜 제한 확인.
미실시: 신규곡 생성/청취, 아티큘레이션·믹스 평가, 루프 청취,
게임 적용 후 실제 재생, 크로스페이드, 음소거/SFX 회귀 시험,
Samsung Internet/Chrome/iOS Safari 실기 재생 및 모바일 메모리 측정.
문서만 추가했으므로 빌드를 실행하지 않았다. sparse checkout에서 build.js를
실행하면 전체 에셋 목록이 누락될 수 있어, 구현 시 assets/mesbg 전체 확보가 필요하다.

다음 진행 조건
연결된 Runway 작업 공간을 사용자가 유료 플랜으로 변경하거나,
음악 생성이 허용된 다른 제작 계정/서비스를 확보해야 한다.
현재 연결이 미완료라고 다시 요청하지 않는다.
그다음 모델별 권리와 출력 제약을 확인하고 메인 테마 실제 파일부터
제작 및 청취 검수한다. 영화 수준의 품질을 충족하지 못하면 낮은 품질을
완성 처리하지 않고, 전문 작곡가/고품질 관현악 제작 환경 필요성을 보고한다.
