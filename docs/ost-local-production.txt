무료 로컬 제작 기록 — 2026-10-11

사용자가 PC 무료 모델 설치를 선택했다. 유료 Runway 생성은 사용하지 않는다.
ACE-Step 1.5 공식 코드를 독립 제작 환경에 설치했으며 게임 의존성에는 추가하지 않는다.

제작 환경
GPU: NVIDIA GeForce GTX 1660 SUPER, VRAM 6GB
RAM: 약 32GB
Python 3.12.14 / PyTorch 2.7.1+cu128 / torchao 0.12.0
모델: ACE-Step v1.5 turbo, 2B
방식: batch 1, INT8 weight-only, BF16 emulation, eager attention
텍스트 인코더/VAE는 CPU offload, 양자화된 DiT는 GPU에 유지한다.
FP16 첫 시도에서 손상된 latent(NaN)가 발견돼 음원 저장을 차단했다.
전체 CPU offload 시 torchao의 CUDA→CPU 이동에서 Windows access violation이
발생해, 공식 persistent DiT 경로와 별도 제작 래퍼의 BF16 설정으로 해결했다.
BF16 행렬곱·양자화 linear·convolution은 이 GPU에서 유효한 결과를 확인했다.
첫 제작에서 음악 언어 모델 없이 음원을 출력했으나 사용자가 음악 방향을 거절했다.
재제작에는 공식 acestep-5Hz-lm-1.7B를 추가했다. 같은 6GB GPU에서
구성 설계와 음원 렌더링을 별도 프로세스로 순차 실행해 동시 적재를 피한다.
게임에는 모델이나 Python 환경을 넣지 않고 압축한 오디오 파일만 제공한다.

프로그램 위치: 현재 작업 폴더의 ost-tools/ACE-Step-1.5
모델 위치: D:/mesbg-ost-models/ACE-Step-1.5 (SSD)
무손실 제작 후보 위치: 현재 작업 폴더의 ost-production/candidates

모델 구성: acestep-v15-turbo, Qwen3-Embedding-0.6B, vae, acestep-5Hz-lm-1.7B
첫 렌더링 구성은 약 6.34GB이고 재제작 구성 모델은 약 3.76GB를 추가한다.
이 모델 파일은 PC의 제작 환경에만 있으며 게임 다운로드와는 무관하다.

사용 권리
코드: https://github.com/ace-step/ACE-Step-1.5 (MIT)
모델: https://huggingface.co/ACE-Step/Ace-Step1.5 (MIT)
공식 모델 카드가 생성 음악의 상업적 사용을 허용한다고 명시한다.
공식 라이선스/모델 카드와 revision을 기록하고, 생성 파일의 해시를 별도로 보존한다.
영화 OST나 외부 참조 음악 파일을 입력하지 않는다. 별도 샘플 라이브러리는 사용하지 않는다.
생성·편집·게임 배포 허용 근거와 결과물 자체의 독창성 검수는 별개이며,
기존 영화의 인지 가능한 선율과 유사한 후보는 완성곡으로 채택하지 않는다.

검수 기준
실제 무손실 음원 출력 → 악기·선율·전개 청취 → 루프 편집 → 음량 측정
→ 모바일 압축 → 브라우저 재생·전환·설정 회귀 검증 순서로 진행한다.
첫 후보를 영화 수준의 완성본이라고 표시하지 않는다.
첫 제작 방향은 7곡의 파일 출력까지 진행됐으나, 대표 메인 후보의 사용자
청취 결과 반지의 제왕의 분위기와 게임에 어울리지 않는다는 피드백을 받았다.
이 방향의 후보는 미채택이며 게임 적용을 보류했다. 실험한 재생 코드도
원복했고 게임 소스, 그래픽, 배포 파일과 기존 BGM은 변경하지 않았다.
메인과 로한 두 곡을 새로운 구성 설계로 먼저 제작하며, 청취 검수 전에
나머지 곡에 이 방향을 일괄 적용하거나 7곡 완성으로 보고하지 않는다.

재제작 출력 및 검증
main-v2: 96초, 48kHz stereo FLAC 원본, 감상용 MP3 2,305,296 bytes
rohan-v2: 90초, 48kHz stereo FLAC 원본, 감상용 MP3 2,161,728 bytes
두 원본 모두 유효한 샘플과 비무음 신호를 확인했다.
감상용 MP3 측정: 각각 -18.53 LUFS, true peak -3.13 / -2.27 dBTP.
새 도입부를 보존했고 루프 연결은 아직 편집하지 않았다.
Codex 내장 Chromium 브라우저의 별도 감상 페이지에서 두 파일의 재생,
재생 시간 진행, 각각 96/90초 길이, 오류 없음과 한 곡 재생 시 다른 곡
일시정지를 확인했다. 게임 안의 전환 테스트나 삼성 인터넷/iOS Safari
실기 검증은 수행하지 않았으며, 음악적 적합성은 사용자 검수 대기다.
사용자의 추가 요청은 영화 OST에 매우 가까운 느낌이다. 기존 OST의
선율이나 고유한 편곡을 거의 복제하는 제작은 진행하지 않는다.
음악적 스타일을 참고하는 독창적 관현악 제작으로 범위를 유지한다.
현재 이 문서는 제작 환경 기록이며, 최종 음원 품질이나 실기 테스트 완료 증명은 아니다.
main 병합 및 배포는 사용자 승인 전까지 하지 않는다.
