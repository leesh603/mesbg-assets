미들어스 워밴드 — 음향 전면 교체 작업 기록 (2026-10-14)

사용자가 재제작 BGM 방향을 수용하고 자동 8배속을 고려한 BGM·효과음 전면 교체를 요청했다.
최신 main 741546502e8c3828b54f3a005e352e3b5501ab0e를 작업 브랜치로 가져와 작업했다.
브랜치: feat/original-orchestral-ost. main 병합·배포는 하지 않았다.

음원 및 위치
메인 — 중간계의 황혼: 94.75초. 현악기·호른·목관·합창, 황혼과 원정의 무게. 메인 전용.
로한 — 황금빛 초원의 기병: 88.75초. 북유럽 피들·현악기·호른, 애가와 기병 리듬. 로한 배치.
곤도르 — 백색 도시의 수호자: 106.75초. 금관·남성 합창, 오래된 왕국과 최후의 항전. 곤도르 배치.
모르도르 — 검은 대지: 106.75초. 저음 합창·저음 금관·현악기, 어두운 행진. 모르도르 배치.
전투 — 검과 방패: 130.75초. 현악 리듬·호른·절제된 타악기, 반복 가능한 긴장. 일반 전투.
영웅/보스 — 최후의 전열: 130.75초. 관현악·합창, 위협과 영웅적 저항. 보스 및 접촉한 영웅 교전.
종료 — 전쟁이 끝난 자리: 64초. 현악기·오보에·첼로·클라리넷, 희생과 안도. 보상/결과에서 1회 재생.
나머지 지역의 배치에는 곤도르를 사용한다. 곡별 콘셉트는 제작 의도이며 전체 음악적 청취 검수는 대기다.
실제 파일: assets/mesbg/audio/ost/*.mp3, *.opus. FLAC 원본은 저장소 밖 ost-production에 보존.
6곡의 반복 연결은 1.25초 끝/머리 혼합으로 편집했다. 전투 종료곡은 반복하지 않는다.

효과음
일반 30종, 74개 변주와 고속 74개 변주, 보스 연출 4종: WAV 152개.
합성 타격·비프·주사위 소리를 녹음 기반 금속/나무/가죽/주사위 소스로 교체했다.
공세 시작·승패 신호는 새 원본 OST에서 짧게 편집했다.
고속용 주요 타격은 대략 0.1–0.25초이며, 음정을 8배로 올리지 않는다.
8배속: 효과음 동시 최대 4개, 낮은 우선순위 소리 최대 8회/초, 주사위 최소 900ms 간격.
타격 계열이 공유하는 135ms 간격과 최근 타격 때 이동/휘두름 소리를 억제하는 처리를 적용했다.
선택·확인·승패 신호는 우선순위를 두고, 공세 시작 신호는 1.8초 이내 반복하지 않는다.
늦게 로딩된 효과음은 재생하지 않으며 음소거·탭 숨김·배속 변경 이전 요청도 폐기한다.
볼륨은 기존 설정/음소거와 연동하며, Web Audio gain과 효과음 전용 필터·압축을 사용한다.
음악은 배속에 따라 바뀌지 않으며, 두 스트리밍 요소로 1.25초 장면 전환을 수행한다.
효과음 다운로드 중복 방지 및 디코딩 캐시 8MiB 제한을 적용했다.

용량
MP3 7곡: 17,351,454 bytes. Opus 7곡: 12,464,369 bytes.
일반/고속 효과음: 1,978,156 bytes. 보스 연출: 1,296,716 bytes.
브라우저는 가능한 경우 Opus를 선택하며 실패하면 MP3로 전환한다. 두 형식을 함께 다운로드하지 않는다.
선택한 곡만 스트리밍하며 전환 중 최대 두 곡을 사용한다. 모델·제작 환경은 게임에 포함하지 않는다.
사용하지 않는 기존 BGM 14파일, 21,348,484 bytes를 제거했다.
기존 효과음 5,733,252 bytes 대신 약 3.27MB를 사용한다. 합계 음원 저장 용량은 약 33.09MB.
기존 음악+효과음 대비 약 6.01MB 증가한다. 최초 메인 Opus는 약 1.56MB이며 음악 전체를 선로드하지 않는다.
