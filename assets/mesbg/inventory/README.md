# 픽셀 인벤토리 아이콘 144종

유물 69종·장비 65종에 적용된 그림과 확장 그림 10종입니다. 효과·희귀도·아이템 ID는 기존 게임과 같습니다. 확장 그림은 아직 아이템으로 등록하지 않았습니다.

- `atlases/`: 1024×1024, 4×4 아틀라스 9장.
- `manifest.json`: 아이템 ID, 원본 프레임 좌표와 내보낸 파일 경로.
- `icons/`: 셀을 그대로 잘라 낸 256×256 RGBA PNG 144장.
- `node tools/extract-inventory-icons.cjs`: 원본 아틀라스에서 아이콘 재생성.
- 게임 경로는 `inventoryIconPath()`와 유물·장비의 실제 ID를 사용합니다. 중복된 옛 파일 경로로 그림을 재사용하지 않습니다.
- 이후 게임 코드를 수정하면 `node tools/build.js`로 빌드하세요.
