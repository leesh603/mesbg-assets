# 영입 소유와 전투 출전 한도 분리

기준 main: 486b2e20dd8a7a7a3b0df2b7798857e8a47d80d6. 병행 반영된 #38의 유닛 크기·중심·캐시 최종 교정도 보존한다.

금화·영입 해금·유니크 인물 조건을 만족하면 출전 포인트와 무관하게 영입한다. 현재 출전 한도 또는 배치 공간에 들어가지 않는 동료도 영입 비용을 지불하고 대기 부대로 보관한다. 시작 영웅 1기 규칙, 일반 병사 수량 영입 및 최초 포인트를 유지하는 승급은 그대로다.

출전 준비의 ‘출전 편성’에서 모든 보유 유닛의 이름·체력·포인트·출전/대기를 보고 교체한다. HUD는 출전 포인트/한도와 대기 인원을 분리한다. 출전 인원이 없거나 한도를 초과하면 전투 시작 전에 차단하며 라운드·스테이지·참전 XP를 소비하지 않는다. 탈것 구매도 소유 한도로 막지 않고 최종 출전 시 검증한다.

대기 유닛은 살아 있는 보유 부대이며 유니크 영입 중복 판정·보유 관리·저장·불러오기·다음 전장 전환에 유지한다. 전투 행동·표적·충돌·결속·전력 기반 다크 이벤트·승패 생존 수·참전 경험치에서는 제외한다. 전장 부대가 전멸했을 때 대기 부대가 패배를 무효화하지 않는다.

검증 명령: `node --test tests/*.test.cjs` 및 `BROWSER_EXECUTABLE=<chromium path> node tests/warband-deployment-browser.cjs`. 실제 Phaser에서 335pt 영입 / 300pt 출전 한도, 두 영웅 교체, 모바일 390×844, 저장 복원, 선택된 간달프만 참전하고 아라곤은 대기하는 시나리오를 확인했다. `browser-report.json`과 화면 3장 참조.
