|---|---|---|
| 진영 보너스가 있는 새 영입 | 최대 체력이 늘어도 현재 체력이 원본 수치. 엘프 병사 1/2, 아르웬 2/3으로 합류 | 단일·수량 영입 모두 최종 편성 보너스를 반영한 완전한 체력·자원으로 합류. 기존 부상은 회복시키지 않음 |

| 오스길리아스 검방·창방·궁병 | 한쪽 다리·발의 연결이나 지지 자세가 어색함 | 세 병종 각각 재제작. 양쪽 다리와 접지한 부츠, 안정된 자세, 기존 쿼터뷰·픽셀 화풍 유지 |

## 숙련 단계

| 단계 | 조건 | 누적 효과 |
|---|---|---|
| 숙련병 | 경험치 12 · 실제 참전 2회 | 결투 최저 주사위 재굴림, 용기 +1 |
| 노련병 | 경험치 30 · 실제 참전 4회 | 위 효과 + 결투 +1, 방어 +1 |
| 백전병 | 경험치 66 · 실제 참전 8회 | 위 효과 + 상처 +1, 근접병 공격 +1 / 궁병 정지 사격의 실패한 상처 주사위 재굴림 |

숙련은 병종 승급·기마 전환 뒤에도 유지하며 최초 편성 포인트를 바꾸지 않는다. 지원용 임시 병력·영웅·괴수에는 병사 숙련을 적용하지 않는다. 기존 저장의 개인 영구 능력치와 유물은 보존한다. 새로운 훈련 상한은 이후 이벤트부터 기록한다. 새로 생긴 최대 체력 한 칸은 한 번만 부여하고, 갱신·불러오기·변환으로 회복이 반복되지 않는다.

## 실제 판정 비교

`tools/report-warband-growth.cjs`가 실제 게임의 결투·사격 판정기를 사용한다. 사례마다 2,000회, 같은 난수 시드, 평지·유물·영웅 능력 없이 비교했다. 결투 우선권은 번갈아 적용했다. 아래 수치는 전체 스테이지 승률이 아니라 **동일 우루크 검방병과 한 번 결투했을 때의 승률**이다.

| 미나스 티리스 검방병 | 수정 전 | 수정 후 |
|---|---:|---:|
| 신병 | 52.55% | 52.55% |
| 숙련병 (2회 참전) | 52.55% | 65.60% |
| 노련병 (4회 참전) | 52.55% | 73.25% |
| 백전병 (8회 참전) | 52.55% | 82.40% |

동일 우루크를 향한 미나스 티리스 궁병의 정지 사격 상처 확률은 신병 15.75%, 백전병 26.85%였다. 재굴림은 명중한 사격의 실패한 상처 주사위에만 적용하며 영웅적 수비 6+, 사격 방패 등 후속 방어 판정을 유지한다. 이동 사격에는 적용하지 않는다.

1·4·5·10스테이지별 각 2,000회 유물 선택 시뮬레이션과 별도로, 진행 경계 8개에서 각각 1,000회 유물 선택·랜덤 이벤트 경로를 검증했다. 1스테이지 최상위 유물은 2,000회 선택에서 109개 → 0개로 바뀌었다. 원시 결과는 `before.json`, `after.json`에 있다.

검증: 전체 자동 테스트 88개, 실제 Phaser의 3종 아트·390×844 모바일·후반 신병/숙련 병력 실제 능력치 확인. 기존 영입 가중치·다크 이벤트 진행 제한·승급·포인트·저장 회귀 검사를 포함한다. 추가한 검토용 이미지 분석은 게임 실행 중 수행하지 않는다. 숙련 계산은 3개 단계의 숫자 비교이며 선배 전수는 영입 시에만 계산한다.
