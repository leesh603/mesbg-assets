# 원화 제작 고정 기준

사용자 재확인: 2026-10-20. 하이앵글 프론트뷰·픽셀 그림체·인간형 5등신을 동시에 지킨다.

- 인간형 목표는 정확히 5등신이다. 4등신으로 축소하거나 6등신 이상으로 늘린 결과를 통과시키지 않는다.
- 머리 한 단위는 해부학적 정수리부터 턱까지다. 머리카락 부피, 수염, 투구 꼭대기·깃·왕관을 머리 길이에 포함하지 않는다.
- 의복·무장을 입힌 새 제작물을 다음 제작물의 체형 기준으로 삼지 않는다. 도보형은 유효한 종족별 해부 기준을 비교한다. 기마형은 폐기된 공통 뼈대로 돌아가지 않고 자세별로 머리·어깨·골반·팔·다리와 기승 구조를 함께 재구성한다.
- 인체 기준: `art/rebuild-skeletons/bases/human.png`. 이전 기마 기준 `art/rebuild-skeletons/bases/human-mounted.png`는 비례 오류로 사용 중단한다. 이것과 이전 수정본을 새 기마 체형 기준으로 사용하지 않는다. 기마는 말 전체 높이가 아닌 기수의 인체를 별도로 검사한다. 기수 전체나 말 전체를 일괄 축소하여 대두 문제를 해결한 것으로 처리하지 않는다.
- 날씬함·건장함 등의 변주는 폭·근육·자세로 표현하며 등신 비율을 바꾸지 않는다. 호빗·난쟁이·괴수는 이미 정한 종족별 표준을 따른다.
- 카메라는 앞에서 아래로 내려다보는 하이앵글 프론트뷰다. 정수리·양쪽 어깨 윗면이 명확히 보이고, 가슴·얼굴은 위에서 본 원근으로 단축되어야 한다. 기마는 말의 목·기갑·안장 윗면도 보여야 한다. 눈높이 정면 원화에서 머리만 숙인 것은 시점 교정으로 통과시키지 않는다.
- 시점·고개 자세 비교 기준: `art/rebuild-skeletons/references/theoden-user-style.png`, `art/gondor-rebuild-20261019/units/warrior_minas_tirith.png`. 잘못된 기존 기마 원화는 캐릭터·무장 참고에만 사용하며 카메라까지 보존하지 않는다. 정면 방향은 유지하고 측면뷰·수직 탑뷰로 바꾸지 않는다.
- 고개는 전반적으로 기존 유닛처럼 살짝 숙이고, 턱과 시선은 앞쪽 아래로 향한다. 정면 카메라를 바라보거나 턱을 드는 자세를 기본값으로 삼지 않는다. 고개 숙임과 카메라 고도는 각각 별도로 검사한다.
- 픽셀 밀도·계단식 윤곽선·색감·명암은 신규 곤도르·모르도르 기준이다. 매끈한 일반 일러스트로 바뀐 결과를 통과시키지 않는다.
- 프롬프트에 '5등신'·'하이앵글'을 적은 사실만으로 검사 완료로 처리하지 않는다. 생성 결과 자체를 기준 뼈대·시점 원화와 비교한다. 비율·시점·그림체 중 하나라도 벗어나면 수정하거나 보류한다.
- 저장된 원화는 사용자 승인 전 검토본이며, 개수 집계는 캐릭터 ID 기준으로 한다. 대체 시안·이전 수정본은 중복 집계하지 않는다. 사용자에게 불합격된 수정본을 완료본이나 새 기본 원화로 채택하지 않는다.

## 2026-10-20 전체 재점검 추가 기준

- 기존과 신규를 같은 표시 조건으로 나란히 비교한다. 시점·비율 기준 충족은 필요조건이며 기존보다 완성도·동세·실루엣이 나빠진 결과는 불합격이다.
- 기존 포즈의 몸 기울임, 무기 사선, 탑승체 걸음과 캐릭터의 관계를 살린다. 모든 기수를 뻣뻣한 정면 자세로 통일하지 않는다.
- 기존이 더 낫거나 신규의 우위가 불명확하면 기존 유지 또는 보류한다. 재제작 개수를 늘리기 위해 열화본을 채택하지 않는다.
- 머리를 줄인 뒤 어깨·팔·손이 과장되거나 목·기승 자세가 무너진 결과도 불합격이다. 투구·머리카락의 시각적 부피까지 검사한다.
- 스란두일 기마: 사용자는 기존의 돌진 동세·숙인 고개·실루엣을 선호하고 신규의 정면화·대두를 거부했다. 엘프 기마기사·글로르핀델 기마도 이전 수정본 불합격이다.
- 전체 제작분 검수 완료 전 '전체 품질 통과' 또는 '비율 수정 완료'라고 보고하지 않는다.


## 2026-10-20 기마 뼈대 사용 중단 및 전신 재구성

- 사용자가 공통 기마 뼈대의 심각한 비례 오류를 지적했다. 기존 human-mounted.png는 폐기된 체형 기준이며 이후 제작의 기준이나 승인 증거로 사용할 수 없다.
- 각 원본의 좋은 동작을 참고해 기수의 머리·목·어깨·상완·하완·손·골반·허벅지·종아리·발을 하나의 인체로 다시 구성하고 안장·등자·고삐·탑승체와의 연결을 검수한다. 머리만 축소하는 방식은 금지한다.
- 새로운 완성 기마 원화 하나를 모든 기마의 공통 뼈대로 고정하지 않는다. 체형 목표는 유지하되 동작과 탑승체 종류에 따라 개별 골격과 투영을 검사한다. 인간/엘프 기수의 5등신 목표와 난쟁이·오크 등의 종족별 체형은 구분한다.
- 투구·머리카락·수염까지 포함한 시각적 머리 비중, 얼굴의 숙임과 카메라 고도는 별도 검사한다. 고개를 숙인 눈높이 정면뷰로 하이앵글을 대신하지 않는다.
