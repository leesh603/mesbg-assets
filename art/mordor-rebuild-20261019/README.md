## 제작 기준

승인된 `0b46e78` 시험작의 완성 오크·우루크·인간·엘프·기마를 첫 구조 참조로 사용했다. 높은 위치에서 내려다보는 정면에 가까운 사선 시점, 머리·어깨·발의 윗면, 짧게 압축된 몸통과 다리, 인간형 5등신 중심의 비율 및 픽셀톤을 유지한다. 자세 때문에 카메라와 비율을 바꾸지 않는다.

초기 생성본에서 정면 시점과 긴 비율로 흐른 문제를 사용자에게 지적받아 **첫 생성본 전량을 채택 중단하고 재제작**했다. 탈락본은 이 브랜치에 포함하지 않았다. 트롤 얼굴이 오크처럼 보인 생성본도 얼굴과 귀를 다시 제작했다.

일반 오크, 모라논, 우루크, 인간형 정예, 영웅, 기마, 괴수의 체형을 구분했다. 상체 기울기, 어깨 폭, 배와 팔의 두께, 무기 운용, 지휘·조준·재장전·방패 밀기·내려치기 등의 자세를 달리했다. 미니어처 참고는 정체성·무장·재질에만 사용하며 미니어처 사진의 정면 시점을 그대로 가져오지 않는다.

## 대상 범위

기준 `units.json`의 모르도르 **46개 ID**와 진영 분류에 상관없이 나즈굴 **27개 ID**를 합친 73종이다. 같은 원화를 쓰던 `orc_bow/orc_archer`, `orc_spear2/orc_spearman` 등도 별도 자세로 새로 만들었다. 나즈굴은 도보 14개·기마 11개·펠비스트 2개이며, `nazgul-manifest.json`으로 누락을 검사한다. 현재 완료 수와 미완료 ID는 `catalog.json`의 `count`, `plannedCount`, `pending`에 기록한다.

실제 GW 미니어처가 있는 병종·영웅은 기존 에셋과 공식 모델 자료를 함께 참고했다. 안나타르, 사우론 늑대, 일부 모르굴 확장 병종·영웅·기마 등 게임용 해석이 포함된 항목은 기존 게임 정체성을 이어가며, 전부를 GW 제품의 정확한 재현이라고 주장하지 않는다. 원본 게임의 병과·스탯은 바꾸지 않는다.

## 보기

`gallery.html`을 웹 서버로 열면 다음을 사용할 수 있다.

- 한글 이름/ID 검색, 보병·영웅·기마·괴수·지원 필터
- 원화 확대, 기존/신규 원화 비교
- 원하는 유닛 여러 기 소환, 드래그 이동·개별 삭제·전체 삭제
- 모르도르/초원 지도, 표시 배율, 기존/신규 전환, 몸체 중심과 측정선
- 배치 화면 PNG 저장

이것은 **아트 검토용 맵 배치 도구**다. 전투·이동·충돌이나 본게임 에셋 교체를 실행하지 않는다.

## 크기와 정렬

`landmarks.json`에 개별 원화의 정수리–발끝, 기수 정수리–앉은 골반, 몸체 중심을 검토해 기록했다. 창·깃·무기·망토 끝은 크기 기준에서 제외한다. 나즈굴 도보는 큰 인간 기준98, 기마·펠비스트는 기수 정수리–앉은 골반 기준50을 사용한다. 일반 기마도 종류별 기수 기준(오크39/인간50)을 사용한다. 일부 게임 데이터에 기마 역할과 도보 원화가 섞여 있어 신규 기마의 제안 프로필은 기수 기준으로 독립 기록했다. 운영 프로필은 바꾸지 않는다.

`catalog.json`은 제안 표시값이다. 작은 오크와 큰 오크는 제한적인 키 변주를 주고 체형 차이는 원화로 구분했다. 기존 감사표에 없는 승급병 2종의 기존 비교값은 해당 원화를 별도로 확인해 오크 기준값으로 기록했다. 알파 외곽 정규화로 몸체 크기를 산정하지 않는다.

## 파일

- `units/`: 새 PNG. 원본 픽셀과 생성 알파 보존.
- `thumbs/`: 목록·맵에 사용하는 512px 이내 축소본. 확대 시 원본을 연다.
- `references/old/`: 기준 main 원화 73개. 비교 전용.
- `references/trial/`: 승인된 시험작의 구조·화풍·지형 참조.
- `references/gw/`, `sources.json`: 공식 미니어처 참고 사진과 출처·사용 목적.
- `unit-specs.json`, `prompts.json`: 유닛별 자세·체형·무장 지정과 최종 ImageGen 지시문.
- `catalog.json`, `landmarks.json`: 원화 크기·해시·몸체/기수 기준점·표시 제안.
- `verification.json`: PNG 해상도·RGBA·투명도·보이는 윤곽 경계·해시 검사. 이 검사만으로 미술 품질을 판정하지 않는다.
- `tools/build_catalog.py`, `tools/render_previews.py`: 목록/검사/프리뷰 재생성.

프리뷰: `previews/mordor-units.png`, `old-vs-new.png`, `mounted-comparison.png`, `terrain-placement.png`.

모라논 검방의 다리 교차 문제를 골반–무릎–정강이–발이 각자 이어지는 짧은 엇선 자세로 다시 그렸다. 완성된 나즈굴은 생성 직후 개별 저장하며 갤러리에 순차 반영한다.
