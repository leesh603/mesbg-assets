# 글로르핀델 도보·기마 비율 재검토

도보형 인체를 참조해 기마형을 재제작한 2종 시안이다. 사용자가 재지적한 소두 기마형과 일괄 머리 축소 방향은 제외했다. 사용자 검토 대기이며 main 병합·배포 및 본게임 교체는 하지 않았다.

[도보·기마 나란히 보기](https://htmlpreview.github.io/?https://github.com/leesh603/mesbg-assets/blob/art/glorfindel-same-body-20261020/art/glorfindel-anatomy-match-20261020/index.html)

인체 비율은 같은 사람으로 유지하고, 승마 자세와 고개 회전으로 구분한다. 이미지 생성 도구는 image_gen이며 최종 프롬프트와 검사 범위는 production.json에 보존했다.
